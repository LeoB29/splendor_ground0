Date frozen: 2026-08-18

## Purpose

Experiment 104 ended searched gen11/gen8 at 54.5%, one win below its 55%
practical gate, while raw gen11/gen8 was 49% and gen11 search/raw was 69.25%.
Experiment 105 distinguishes an evaluation fluctuation from a genuine learning
plateau and attributes any plateau before more self-play compute is spent.

## Existing-data forensic audit

No new training or self-play is allowed. From each replay, select all states in
the 16 complete games at seed offsets
`[3,19,27,44,58,73,89,104,121,137,152,168,183,201,223,247]`.
This fixed sample spans the full seed band without outcome-based selection.

Run all four checkpoints on every selected replay state and report a common
checkpoint-by-corpus matrix containing policy cross-entropy to the stored
search visits, value MSE/MAE, policy-top agreement, decisive-state agreement,
raw action-family rates, checkpoint-pair total variation, and top-action
change. Comparisons across checkpoints on one corpus are valid common-state
comparisons; absolute losses across different corpora are descriptive only.

Reconstruct one state from each selected game, targeting turns
`[6,10,14,18,22,28,34,40,46,49,52,54,56,58,60,62]`. On these 64 common states,
run each checkpoint with 256 simulations, `c_puct=2.25`, real mode, no root
noise, and frozen deterministic seeds. Report prior-to-visit movement,
raw/visit action-family rates, search value movement, and reserve-deck prior,
visit, and Q behavior.

On the same 64 complete source games, trace every selected `RESERVE_DECK`
action through the deterministic true game state. Report its revealed card,
eventual purchase rate, time to purchase, remaining game horizon, and the
reserving player's eventual outcome. These are associations, not causal action
values.

The complete offline audit is written atomically. If interrupted before it is
sealed, only this relatively cheap audit may repeat.

## Independent replication and pooled assessment

After the offline audit, run exact searched gen11 against exact searched gen8
on fresh seeds `1930000..1930099`, both seats, for 200 games. Use the unchanged
256-simulation / `c_puct=2.25` real evaluation operator with no root noise.
Commit every game atomically and resume only an exact schedule prefix.

Pool the 200 new games prospectively with the exact 200 primary rows frozen in
104. Report the 400-game score share, mean margin, both seats, all termination
reasons, and a 50,000-sample paired bootstrap over 200 seed pairs. The existing
practical definition remains: at least 55%, positive margin, both seats at
least 50%, and all normal completions. The interval is evidence strength, not a
new retroactive gate. The new panel is never assessed alone as a second chance.

## Decisions and scope

- A pooled practical pass means the third block is consistent with continued
  compounding; the next separately frozen action may benchmark gen11 against
  `035` before further scaling.
- A pooled result from 50% to below 55% with positive margin and both seats
  nonlosing confirms a practically flat block and uses the offline audit to
  choose between replay retention and stronger network/distillation capacity.
- A worse or unhealthy pooled result requires mechanism diagnosis before any
  continuation.
- Reserve-deck evidence may motivate a targeted causal audit but never removes
  or masks that legal action in 105.
- No `035` game, self-play game, checkpoint training, installation, promotion,
  or architecture change is authorized by this experiment.
