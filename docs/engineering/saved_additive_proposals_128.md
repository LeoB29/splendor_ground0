## Question and source

Does retaining the anchor's fourth proposal while adding a learner's proposal
recover utility that replacement discards? Use all 360 main roots (180 whole
reversed-seat source pairs) of the completed planner_state_transfer_128 study.
The original 18 strata are fit 161001/161002/161003 by phase 0/1/2 by source arm
candidate/reference, with ten pairs each. No selection by disagreement, outcome,
availability, or inferred promise; duplicate proposals and short supports remain.
The source result and final audit hashes are pinned in common.py. Historical
sampled/stress/unresolved simulation audits are authenticated and inherited,
not rerun. Every new choice, assessment, contrast, bootstrap statistic, and cost
count is independently reconstructed using separate code.

This operator was proposed after inspecting previous results. This is reused
development evidence, not a new confirmatory population or a whole-game win rate.
No result for the new unions is computed before the protocol/code/input freeze.

## Arms and exact decisions

Original anchor A, BROAD replacement B, NARROW replacement N, and teacher T retain
their saved candidate order and all 128 selection worlds. A+B is ordered A followed
by B's missing candidates; A+N similarly. Shared three-move prefix means at most
one distinct extra proposal and five total candidates. No duplicate simulations.
The original teacher (up to eight candidates) is context only.

Selection uses only the original 128 selection worlds, with original-order ties.
On exact known outcomes the union winner is the original A winner unless the B
(or N) winner has a strictly greater selection mean. Prove this shortcut against
the complete ordered union on every root. Original winners are also reconstructed.
The disjoint original 128 assessment worlds already contain all possible union
winners. Assess the selected action there; do not report the selection maximum
as an estimated gain or use assessment outcomes to choose an action.

Repetition cutoffs remain unknown WDL in [-1,1]. Certify selection with conservative
integer pairwise bounds: strictly positive against earlier candidates, nonnegative
against later candidates. Separate certification of A/B is insufficient; the union
itself must be certified. The closed source has no coupled equivalence proofs;
any unexpected proof or remaining ambiguity holds this run with evidence preserved.
Never drop a root, rerun a simulation, or impute a draw. Assessment bounds retain
unknowns; selecting the identical saved action cancels uncertainty exactly in a
paired contrast. Any genuine final hold requires review, not automatic recovery.

## Statistics and frozen decision rules

Terminal score is (WDL+1)/2. Paired contrast order:

1. A+B minus A (primary useful gain).
2. A+B minus B (benefit from preserving the old suggestion).
3. A+B minus A+N (broader-supervision attribution).
4. A+N minus A (matched-control context).
5. B minus A, B minus N, N minus A, T minus A (original context).

Use all 180 source pairs as bootstrap units, retaining both reversed-seat legs.
Sample ten whole pairs with replacement within each of 18 original strata, using
50,000 shared draws across all contrasts, NumPy default_rng seed 2203000000,
chunks of 1,000. Stratum order is fit, phase, source arm candidate then reference;
pairs are sorted by original pair ID. Aggregate integer score units of 1/256,
divide by 360, and use linear 2.5/97.5 percentiles. For unresolved differences,
bootstrap the lower and upper envelopes without imputation.

Practical pass requires A+B minus A lower mean at least +0.005 score (+0.5
percentage points) with paired 95% lower endpoint strictly above zero, AND
A+B minus B paired 95% lower strictly above zero. Broader-learning attribution
additionally requires A+B minus A+N paired 95% lower strictly above zero.
Report practical and attribution passes separately. Teacher gains cannot rescue
these gates. These are frozen investment hurdles on development evidence, not
claims of controlled familywise confirmatory error. No arm or threshold sweep.

## Costs, limits, and implications

Count actual unique candidate allocations on every root. A fifth distinct move
adds 128 selection continuations (up to 25% on four-candidate roots); duplicate
proposals add none. Report panel totals and original recorded learned_extra_wall
for the extra learner inference, explicitly not a new deployment timing benchmark.
The union is not equal compute to A/B. Generic benefit from an additional candidate
remains a rival explanation; sparse assessment cannot supply a random-fifth arm.

A clear practical development pass can justify proposing one bounded fresh
confirmation including a random fifth-slot control. A small/null result closes
this frozen additive-model branch; no nearby sweep, third population rescue,
training, arena, promotion, or automatic confirmation. Attribution requires its
own gate even if both additive arms improve.

The execution is hidden CPU arithmetic with one thread, one-hour hard execution
ceiling and 5 GiB disk reserve. System sleep is inhibited only during execution;
display sleep remains allowed. Exclusive artifacts and one-shot launch preserve
failed/partial evidence. Preflight tests are synthetic plus source authentication;
no new production union endpoint is inspected before freeze. Completion rechecks
the frozen code, input inventory, all 360 analysis receipts and 360 independent
verification receipts. This study's full arithmetic audit is inexpensive and does
not imply full replay of historical inner simulations.
