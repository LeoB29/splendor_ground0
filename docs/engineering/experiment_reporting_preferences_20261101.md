# Standing preference: visually intuitive experiment results

User request, 1 November 2026: whenever an experiment finishes and a chart is
relevant, produce one chart, or at most two, summarizing the key results.

Apply to the current512-versus256 comparison and subsequent experiments.
Use one clear chart by default; add a second only for a distinct important
question, such as strength versus response time. Do not force a chart when it
adds nothing. This is a reporting preference, not authorization for extra
experiments, model calls, monitoring automations or changes to frozen evidence.

Use accepted saved evidence, clearly labelled players, samples, units and
reference lines. Show uncertainty appropriate to the design (paired intervals
for paired games); do not substitute independent-game intervals. Keep research
strength, runtime and one-second deployment claims distinct. Include failures
or incomplete status when material, and never present an unfinished study's
partial score as a completed strength result.

Generate scientific charts with standard plotting tools as standalone artifacts,
save them outside frozen inventories, inspect their appearance and present them
inline with the final result. Use readable labels and simple colors. Preserve
the underlying counts and evidence references; no decorative or misleading axes.

Keep the existing explanatory sections: What this result establishes, The next
step, and The broader picture. Charts supplement those explanations.
