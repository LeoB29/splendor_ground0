gain can admit six fresh operational games. No strength study or training is
included. Preserve all earlier players, sources, evidence and failures.

traced, frozen inference graph. Freeze with numerical optimization disabled;

construction, validation and architecture-only warmup occur inside the charged
worker initialization allowance. Save its settings, runtime identity, graph
identity and qualification evidence. Never remove a failure and rebuild another
candidate within this attempt.

The baseline is the verified eager worker with optimized process sampling and
the raw response reader. Both parents retain that exact reader and sampler.
The failed buffered-reader candidate is not promoted. Keep the exact inherited
checkpoint, float32 CPU, one numerical thread, assigned performance-core logical
processor, original supported batches1/2/8, 32/64 simulation quotas, three worlds,
depth64, action mapping, native binaries and complete scientific responses.
The checkpoint retains its historical training origin.

Keep 1.000 seconds from the original trusted request clock to complete-response
arrival and the .900-second internal fail-closed clock. No measured component or
preprocessing cost is subtracted. The .700-second operational admission margin
remains required. Keep all resource monitoring, legal/privacy checks, independent
transitions, lossless logging, native role ownership and cleanup checks.

Every actual evaluator worker and the parent authenticates corrected runtime
sources at startup. Actual baseline and candidate entrypoints at both quotas
must pass the preserved 52-decision corrected-face, encoded-cost, noble, payment,

## Exact numerical qualification

Before timed saved-position comparisons, compare eager and graph execution on
a fixed bounded set of nonzero recorded public input tensors and all supported
batch shapes, plus architecture-zero controls. The frozen plan and source hashes
must identify the fixtures before model calls. Require float32 dtype, original
output shape, finite values and exact bitwise float32 equality. Save expected
and actual output evidence, including the first mismatch if any. Signed-zero
differences must not be hidden by ordinary Python numeric equality.

The numerical fixture set has11 cases: six distinct nonzero batch1 first-callback
inputs, in source order, from the completed component diagnostic's eager64
entrypoint forensic records; a batch2 concatenation of the first two; a batch8
concatenation cycling those six; and zero controls at batches1/2/8. Bind the
source file, line identities and exact input bytes. Every candidate process
must pass this fixed set, within a60-second supervised request, before serving
an entrypoint batch or player decision. This qualification allowance is not a
move allowance; ordinary moves retain the1.000-second limit.

Keep numerical qualification separate from ordinary timed player decisions:
the deployed candidate must not run an eager shadow on each move. Full callback
hashes, scientific traces, actions and corrected transitions then have to match
between eager and candidate in the saved-position comparison. Where historical
scientific records exist, those must match too. Any numerical or decision
mismatch stops the attempt; do not weaken tolerances, accept equal actions alone
or relabel a differing player as a behavior-preserving optimization.
