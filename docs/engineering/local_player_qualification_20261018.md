# Local player correctness and deadline qualification

18 October 2026. The owner authorizes implementation and one bounded execution,
followed by external-opponent qualification and a conditional 60-game screen.
The larger-data study remains deferred. This protocol concerns sampled
correctness and practical latency, not new playing-strength evidence.

The numerical players remain the frozen learned four-candidate and breadth
eight-candidate selectors, each using 128 worlds and the three original 161
models with frozen 035 continuations. No partial result, fallback, reduced world
count, faster numerical backend or changed model is accepted as their decision.
All changes live in a new qualification package; original code and evidence are
hash checked before and after execution.

## Frozen panel and execution order

Select 18 candidate-side roots from the completed breadth main arena, one per
fit (161001/2/3), acting seat (0/1), and phase (turns 0–19,20–39,40+).
Selection uses the minimum fixed identity hash within each cell, using the
authenticated historical audit metadata inventory without consulting decisions,
outcomes or measured time. Add at most five distinct metadata-selected saved
roots covering own private reserves, opposing private reserves, both, short
support and intermediate support where present. Report missing strata.
Ties and clock faults are synthetic fixtures and do not select historical roots
using outcomes. Save identities, eligible counts and original record hashes
before executing any production decision.

Run each selected position with each player at each of the 1-second and
120-second allowances, alternating player order by panel index. Each attempt
gets a newly initialized worker, so timing failures cannot contaminate later
cases. These are separate declared budget cases, not retries of a failed case.
The 120-second attempts also reveal whether a completed decision met one second;
the separately enforced one-second attempts validate actual cancellation.
After the main panel, repeat the first core position for each fit and player at
120 seconds with identical lawful input/RNG, including a hidden-state
permutation before observation construction. Compare completed repetitions with
the original records and each other. Timeouts remain failures and cannot be
reclassified using a later successful repetition.

## Observation boundary and correctness

Only the legal observation, own private information, public hidden-reserve
counts/tiers, public deck counts and declared player randomness enter the worker.
The referee retains original true states and expected records privately. A
canonical lawful completion of unknown cards is only an input to the unchanged
observer determinizer, never the actual hidden world. Compare legal actions,
proposals, representative actions, original four-prefix, model identity, all
128 world seeds and reconstructed-world hashes, every offered continuation's
termination/outcome/trace record, arithmetic means and ordered choice against
the saved evidence. Continuous model values use the established 1e-6 absolute
and relative comparison tolerance; discrete outcomes, identities, trace hashes
and chosen actions must agree exactly. Four-candidate expectations are the
original breadth record's preserved four-prefix, rescored on the same worlds.
This is a counterfactual correctness fixture, not a four-player strength result.

Every completed decision is checked. A mismatch blocks scientific acceptance
and ends production qualification; preserve the failed case and receipt. A
timeout, worker crash or initialization failure remains an operational failure;
continue the other predetermined cases while within the envelope. Repeated
failures are never replaced by selected passing positions.

## Trusted clock and resource limits

Use one numerical thread on one logical thread of a verified physical performance
core, selected by Windows processor topology, identical affinity and normal
priority for both configurations. Record topology and delivered wall/CPU time,
peak RSS, initialization cost and work. This is an isolated single worker; the
host remains an ordinary desktop, so other system activity is a timing limitation.

Initialize models under a separate 60-second limit. Start the move clock before
serializing/delivering input, end at the trusted supervisor's receipt of the
complete response. Reject late responses using that timestamp even if inspected
later. Child timestamps cannot authorize a late action. Timeouts terminate the
process tree, with no background pondering, retained caches or automatic retry.
The worker preserves bounded progress messages every 16 completed worlds; these
do not authorize a partial-search decision. The timed response includes the
scientific trace evidence as well as the chosen action, so receipt overhead is
included in this qualification.
Synthetic tests cover timely, late, malformed, wrong-request, illegal and hung
players, process cleanup, bounded output, and receipt-time semantics.

The execution ceiling is four hours from the launch receipt, including worker
initialization, all attempts, final checks and external static qualification.
No new attempt begins unless its full 60-second initialization and move allowance
plus finalization reserve fit within the remaining budget. Use at most one active
player worker (with a shared OS execution lease), 256 MiB new evidence,
2 GiB worker RSS, and keep at least 5 GiB disk
free. Before each worker require at least 1 GiB available physical memory and
3 GiB commit headroom; record actual availability. Stop and retain partial
evidence at any resource boundary. Disk/artifact/global-time limits are also
polled during work at one-second intervals; eight MiB of the artifact allowance
is reserved for in-flight and final receipts. No data collection or training is authorized.

## Decision and external prerequisite

Report every attempted/completed/failed case by fit, player and clock, separately
for core, edge and repeat cases. Give completed timing distributions and timeout
counts; never turn censored deadlines into observed completion times. Passing
this finite panel does not guarantee universal timing. Breadth stays the
strongest verified local successor; four candidates cannot inherit that claim.
Any timing-based entrant recommendation is fixed before external game outcomes.

External qualification must first establish all 90 component identities and 10
nobles, feature/action semantics, lawful observations and clock behavior at the
pinned source/checkpoint. A catalogue mismatch is a hard prerequisite failure;
do not change either frozen player, silently map incompatible cards, run a
purported same-rules screen, or infer competitiveness from that failure.
If compatible, freeze a separate 30-pair/60-game development schedule with fresh,
collision-checked seeds, paired initial worlds and swapped seats, reset players,
one second per move, PPO against raw 035, all transitions replayed and a
50,000-replicate paired bootstrap before outcomes. A referee defect blocks
acceptance; player timeout/crash/illegal action loses and remains counted.
That conditional screen does not authorize the larger 402-game benchmark.
